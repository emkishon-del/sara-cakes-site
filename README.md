# Sara Cakes & Sweets – קבצי הפרויקט

אתר תדמית וקטלוג לעסק העוגות של שרה בירושלים. הפעולה המרכזית באתר: פנייה בוואטסאפ.

## מה יש בתיקייה

| תיקייה | מה בתוכה |
|---|---|
| `site/` | אב הטיפוס של האתר. פותחים את `site/index.html` בדפדפן, והאתר עובד גם בלי אינטרנט (חוץ מהגופנים). |
| `site/data/catalog.js` | כל העבודות בקטלוג: מספר, קטגוריה, כותרת ותמונה. כאן מוסיפים עבודות עד שיהיה עמוד ניהול. |
| `site/img/` | התמונות לאתר בפורמט WebP: גרסה גדולה וגרסה קטנה (`-sm`) לכל תמונה. |
| `brand/logo/` | הלוגו המעודן: אנכי, אופקי וסמל, ב-SVG וב-PNG שקוף, וגם הלוגו המקורי. |
| `brand/photos-original/` | התמונות המקוריות כפי שהתקבלו (המנה השנייה בתיקייה `batch-2`). |
| `brand/photos-edited/` | התמונות שעברו עריכה: שני השולחנות המתוקים (ניקוי, יישור וחידוד). |
| `docs/` | האפיון המלא (גרסה 7), צילומי מסך של אב הטיפוס, ובתיקייה `reference` תמונת ההשראה והמחירון. |
| `CLAUDE.md` | הנחיות ל-Claude Code, כדי להמשיך מכאן לאתר האמיתי. |
| `HANDOFF.md` | סיכום מלא של הפרויקט להמשך עבודה מחשבון אחר. |

## הוספת עבודה לקטלוג (עד שיהיה עמוד ניהול)

1. שומרים את התמונה ב-`site/img/` בשתי גרסאות: `שם.webp` (עד 1400 פיקסלים) ו-`שם-sm.webp` (עד 640 פיקסלים).
2. מוסיפים שורה ל-`items` ב-`site/data/catalog.js`, עם מספר חדש, קטגוריה, תת-קטגוריה (אם יש), כותרת ושם הקובץ.
3. קטגוריה בלי עבודות לא מוצגת באתר, ולכן סדנאות ומארזים יופיעו אוטומטית כשיתווספו להן תמונות.

## עוד חסר

- תמונות של סדנאות, ופרטים על הסדנאות.
- תפריט הבופה.
- עוד שולחנות מתוקים, מגשי אירוח ועוגיות, ועוגות לחתונה, ברית וחגים.
- מחירים לשולחנות מתוקים, קינוחים, בופה וסדנאות, אם רוצים להוסיף אותם למחירון (`prices` ב-`site/data/catalog.js`).
- תמונה של שרה לעמוד האודות.
- הכתובת של עמוד הפייסבוק אחרי שינוי השם.
- בתמונת הבר הוורוד מופיע קרדיט של הצלמת (Coly Bensiqui). כדאי לבקש ממנה אישור להשתמש בתמונה באתר.

## השלבים הבאים

1. משוב של שרה על אב הטיפוס.
2. מעבר ל-Claude Code: פרויקט אמיתי עם GitHub, Supabase לעמוד הניהול ולתמונות, ואחסון (Netlify, Vercel או Cloudflare Pages).
3. עמוד ניהול, דומיין saracakes.co.il, פרופיל עסק בגוגל, בדיקת נגישות, השקה.
